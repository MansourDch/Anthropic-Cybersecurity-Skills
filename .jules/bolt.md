## 2026-08-05 - glob vs os.scandir in large directories
**Learning:** `glob.glob` can be surprisingly slow on large directories because of implicit `stat` calls, especially when iterating over a large number of directories (like the 800+ skill folders in this repo). `os.scandir` is significantly faster because it returns an iterator of `DirEntry` objects which cache file type information, avoiding the need for extra system calls. In tests on this codebase, `os.scandir` dropped the directory scanning time from ~0.74s to ~0.11s, reducing the total script runtime significantly.
**Action:** Always prefer `os.scandir` or `pathlib.Path.iterdir()` over `glob.glob` when scanning directories if `stat` information (like `is_dir()`) is needed, particularly when the directory structure is flat and broad.
