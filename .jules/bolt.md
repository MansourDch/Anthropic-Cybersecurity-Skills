## 2026-09-05 - Python regex vs string methods for frontmatter parsing
**Learning:** Python's `re.match` is significantly slower than string manipulation like `.find()`, `.replace()`, and `.isalnum()` for validating keys and basic structures when performed repeatedly (e.g., parsing 800+ markdown frontmatters line by line). A single regex execution per line across thousands of lines adds measurable overhead (around 30-50% of the total runtime for a validation script).
**Action:** When profiling reveals regex compilation or matching in a hot loop (like a parser iterating over many lines), replace simple regexes with equivalent string methods, provided it can be done accurately without sacrificing readability. Always remove leftover profiling dump files like `stats` before committing.
